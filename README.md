# 🤖 Divulgador Inteligente Bot

Bot do Telegram desenvolvido para afiliados da Shopee.

## Funcionalidades

- Recebe um link de afiliado da Shopee.
- Obtém automaticamente os dados do produto usando a API Oficial da Shopee.
- Captura:
  - Imagem do produto
  - Nome do produto
  - Preço atualizado
- Gera automaticamente uma arte para Story do Instagram utilizando um modelo fixo.
- Envia a arte pronta diretamente no Telegram.

## Tecnologias

- Node.js
- Telegram Bot API
- Shopee Affiliate Open API (GraphQL)
- Canvas
- Render
